# Proyecto Órbita 1: Diseñar para que funcione
**Autor:** Alejandro Espinosa Leal  
**Módulo:** Diseño de Interfaces Web  
---
## ¿De qué trata mi proyecto?
Es una aplicación web pensada para jugadores competitivos de juegos como **Valorant** o **Fortnite** que buscan compañeros de equipo fiables de su **mismo nivel (rango) y horario**, para no tener que depender del emparejamiento aleatorio (*randoms*), evitar la toxicidad y poder coordinarse fácilmente.
